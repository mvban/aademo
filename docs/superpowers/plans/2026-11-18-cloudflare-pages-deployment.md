# Cloudflare Pages Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Configure Wrangler so the Vite `dist/` output can be deployed to the Cloudflare Pages project `capacitor-app`.

**Architecture:** Keep Vite responsible for producing `dist/`. Use a repository-level `wrangler.toml` for the Pages project identity and npm scripts that build before invoking Wrangler's direct Pages upload command.

**Tech Stack:** Vite, npm, Wrangler CLI, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-11-18-cloudflare-pages-deployment-design.md`

## Global Constraints

- Cloudflare Pages project name: `capacitor-app`.
- Upload directory: `dist/`.
- Production deployment must build before uploading.
- Preview deployment must be available without changing production settings.
- Do not alter Vite or Capacitor runtime behavior.

## Review Focus

- A missing `dist/` must be handled by building first in the deployment scripts.
- The Wrangler project name must exactly match `capacitor-app`.
- A preview deployment must use a separate branch/alias and not imply production.
- README instructions must identify the required Wrangler authentication step.

### Task 1: Add Wrangler configuration and deployment scripts

**Files:**
- Create: `wrangler.toml`
- Modify: `package.json`
- Modify: `bun.lock` if dependency installation updates it

**Interfaces:**
- Produces: `npm run deploy` builds and runs `wrangler pages deploy dist --project-name capacitor-app`.
- Produces: `npm run deploy:preview -- --branch=<name>` builds and runs a branch deployment.
